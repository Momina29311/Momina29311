I'm a Data Science engineer who turns messy, real-world data into production-ready ML systems. My focus is building explainable, end-to-end pipelines — from raw data to a model a non-technical stakeholder can actually trust. ### 🔥 Now Building

**[ResumeIQ](https://github.com/Momina29311/ResumeIQ)** — an AI-powered resume screener combining a hybrid **ATS + semantic + explainable AI (XAI)** scoring engine. It parses resumes, extracts skills, performs semantic job-matching, scores and ranks candidates, and surfaces hiring insights through interactive analytics — now in the final polish stage as a recruiter-ready portfolio project.
